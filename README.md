# TEHNet-FocusDet

Official repository of the paper

> **Rethinking Focus-and-Detect for Aerial Small Object Detection under a Frozen-Detector Protocol: A Translation-Equivariance-Guided Approach**
> Chuwei Li, Zhilong Zhang, and Ping Zhong. *Remote Sensing* (under review).

## Status

The code and weights will be released here upon acceptance of the article.

## Planned contents

- The complete inference pipeline: the translation-equivariant heatmap network (TEHNet), heatmap decoding, cropping and super-resolution, image packing, inverse coordinate mapping, and fusion.
- The trained TEHNet weights.
- The weights of the TPH-YOLOv5 detector used in the experiments.
- Scripts to reproduce the results of our method with TPH-YOLOv5 on VisDrone-test-dev.

The super-resolution weights are those released by GLSAN (https://github.com/dengsutao/glsan).
